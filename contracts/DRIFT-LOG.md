# Drift-Log: Entscheidungen

Protokoll aller Entscheidungen zu den Einträgen in [DRIFT.md](DRIFT.md). So lässt sich später
nachvollziehen, **was der Ausgangszustand war**, **was entschieden wurde** und **was konkret
geändert wurde**. Neue Entscheidungen werden unten als neue Runde angehängt.

Legende: ⚪ akzeptiert · 🟢 gelöst · 🟡 entschieden, noch offen.
„per Claude Code“ heisst: Die Änderung hat Claude Code im Auftrag des Teams umgesetzt.

**Vor jeder Entscheidung gegenprüfen:**
- im offiziellen shadcn-Registry (`https://ui.shadcn.com/r/styles/<style>/<komponente>.json`), welchen
  Stand der Code haben sollte;
- im Live-Figma (figma-console), ob der Contract noch stimmt.
